# 🎧 Headphones Landing Page

This is a responsive landing page for **Headphones**, designed to match the provided Figma mockups for **mobile, tablet, and desktop**.

---

## 🚀 Features
- Responsive layout (mobile, tablet, desktop)
- Sticky navigation bar
- Sections:
  - Hero section with CTA button
  - "What we do" features
  - Results section with pentagons
  - Contact form
  - Footer with social media
- Smooth scrolling
- Hamburger menu for mobile view
- Hover animations and transitions

---

## 🛠️ Technologies
- HTML5
- CSS3 (Flexbox + Grid + Media Queries)
- JavaScript (for menu toggle & animations)
- Fonts & icons from Google Fonts / FontAwesome

---

## 📱 Responsive Breakpoints
- **Mobile:** up to 600px  
- **Tablet:** 601px – 1024px  
- **Desktop:** 1025px+
